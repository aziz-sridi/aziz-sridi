# Saitama artwork credits

The active contribution animation uses the original **pixel-art Saitama sprite**, credited to **Hacker93** and shared by **SantinoP** in [Saitama Sprite on Scratch](https://scratch.mit.edu/projects/305192876/).

The shared project uses [Creative Commons Attribution-ShareAlike 2.0](https://creativecommons.org/licenses/by-sa/2.0/). The sprite frames and contribution SVGs containing them are distributed under that license. This does not change the license of other independent files.

The original five idle frames and ten serious-punch frames are preserved without repainting. `frames.json` records their source assets, dimensions, and anchors. The SVG embeds each distinct PNG once and uses timed frame changes with the earlier shockwave and contribution scatter effect. Frame timing and composition were adapted for this profile.

## Shockwave references

The flat amber-and-yellow half-circle shockwave is an original SVG drawing shaped after the user's supplied tapered white reference. The smaller aftershock uses the same silhouette with a shorter fade. The reference image is not embedded. The filled impact burst and sparks are also SVG paths.

Earlier visual research included the crescent silhouettes in [Yangji's 2D VFX study](https://www.behance.net/gallery/204578491/2D-VFX). No artwork from that study is embedded.

The ready-made [yellow hit animation by Sinestesia](https://opengameart.org/content/hit-animation-frame-by-frame), released under CC0, was also reviewed as a reference. Its sprite sheet is not used in the profile.

## Archived chibi reference

Character reference: the **deadpan chibi Saitama illustration** selected as option C, available on [PNGWing](https://www.pngwing.com/en/free-png-cjgmp). The source does not identify the original artist and lists the illustration for non-commercial use.

`chibi-saitama.png` is a transparent cutout prepared from that selected illustration using the built-in image editing tool. Its baked checkerboard background was removed. The [edit prompt](./EDIT-PROMPT.md) records the requested preservation of the character's appearance.

The previous contribution SVGs embedded this PNG once and articulated the fist using SVG masks. The PNG and edit prompt are retained as reference assets.

Saitama and One-Punch Man are creations of ONE and Yusuke Murata. This is unofficial fan artwork for a personal profile.
